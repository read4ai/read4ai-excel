# Benchmark — read4ai-excel v0.1.0

**Date:** 2026-04-18

## Setup

- **Golden set:** 25+ fixtures, 128+ questions (Public + Private)
- **Parsers:** read4ai-excel v0.1.0, pandas 3.0, SheetJS 0.20, calamine 0.6
- **Evaluation model:** OpenAI GPT-5.4 mini
- **Scoring:** rule-based (`exact_value` / `list` / `choice`) + post-hoc human/LLM grading for ambiguous rows

## Results

Evaluation model: **GPT-5.4 mini**

|                 | read4ai-excel v0.1.0 | pandas 3.0 | SheetJS 0.20 | calamine 0.6 |
|-----------------|----------------------|------------|--------------|--------------|
| All features    | 🏆 88.3%              | 82.0%      | 84.4%        | 82.8%        |
| Public features | 🏆 94.0%              | 🏆 94.0%    | 🏆 94.0%      | 88.0%        |

- **Public features**: 10 downloadable `fixtures/*.xlsx` you can reproduce. Mostly clean spreadsheets — every parser scores 88-94%.
- **All features** = Public + a private holdout of feature files with merged cells, stacked tables, and hierarchical headers. read4ai-excel leads by **+3.9 to +6.3pp** on this harder set; complex layout is where strategy choice shows its value.
