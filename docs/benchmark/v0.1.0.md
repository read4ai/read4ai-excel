# Benchmark — read4ai-excel v0.1.0

**Date:** 2026-04-18

## Setup

- **Golden set:** 25+ fixtures, 128+ questions (Real-world + Hidden groups)
- **Parsers:** read4ai-excel v0.1.0, pandas 3.0, SheetJS 0.20, calamine 0.6
- **Evaluation model:** OpenAI GPT-5.4 mini
- **Scoring:** rule-based (`exact_value` / `list` / `choice`) + post-hoc human/LLM grading for ambiguous rows

## Results — All fixtures

| Parser            | Score    |
|-------------------|----------|
| **read4ai-excel** | 🏆 **87.5%** |
| SheetJS 0.20      | 83.6%    |
| calamine 0.6      | 82.8%    |
| pandas 3.0        | 82.0%    |

read4ai-excel outperforms established baselines by **+3.9 to +5.5 percentage points**. The gap widens on fixtures with complex layout (merged cells, multi-table sheets, hierarchical headers).

## Results — Public fixtures
